## 🚀 **Инструкции по запуску:**

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите тесты с измерением покрытия:**
   ```bash
   pytest --cov=src --cov-omit="src/gui/*,src/gui/**/*" --cov-report=term
   ```

3. **Запустите конкретные тестовые группы:**
   ```bash
   # Все новые тесты
   pytest tests/test_gui_imports.py tests/test_authentication.py tests/test_password_policy.py tests/test_windows_memory.py tests/test_key_exchange.py -v
   
   # Только property-тесты (ускоренные)
   pytest tests/test_import_export_properties.py -v
   ```

4. **Сгенерируйте HTML отчет:**
   ```bash
   pytest --cov=src --cov-omit="src/gui/*,src/gui/**/*" --cov-report=html
   # Откройте htmlcov/index.html
   ```
