# Тестирование диалогов ввода пароля для импорта/экспорта

## Что изменено

Добавлена логика запроса паролей для импорта/экспорта:

### Экспорт:
- **JSON**: мастер-пароль (проверяется автоматически) + пароль экспорта (запрашивается через диалог)
- **LastPass CSV**: мастер-пароль + пароль экспорта (запрашивается через диалог)
- **Bitwarden JSON**: только мастер-пароль
- **CSV**: только мастер-пароль

### Импорт:
- **JSON**: мастер-пароль + пароль файла (запрашивается через диалог)
- **LastPass CSV**: мастер-пароль + пароль файла (запрашивается через диалог)
- **Bitwarden JSON**: только мастер-пароль
- **CSV**: только мастер-пароль

## Как тестировать

### 1. Запуск программы

```bash
python main.py
```

### 2. Тестирование экспорта JSON/LastPass

1. Откройте приложение и войдите с мастер-паролем
2. Выберите меню **File → Экспорт** (или нажмите Ctrl+E)
3. Выберите формат **Encrypted JSON** или **LastPass CSV**
4. Нажмите кнопку **Экспортировать**
5. **Должно появиться окно** с заголовком "Пароль экспорта" и полем для ввода пароля
6. Введите пароль (например, "test123") и нажмите OK
7. Выберите место сохранения файла
8. Проверьте консоль на наличие отладочных сообщений:
   ```
   [DEBUG] Запрашиваем пароль экспорта для формата: json
   [DEBUG] Пароль экспорта получен: True
   ```

### 3. Тестирование импорта JSON/LastPass

1. Откройте меню **File → Импорт** (или нажмите Ctrl+I)
2. Нажмите **Обзор** и выберите ранее экспортированный файл JSON или LastPass CSV
3. Нажмите кнопку **Импортировать**
4. **Должно появиться окно** с заголовком "Пароль файла" и полем для ввода пароля
5. Введите тот же пароль, что использовали при экспорте
6. Проверьте консоль:
   ```
   [DEBUG] Запрашиваем пароль файла для формата: json
   [DEBUG] Пароль файла получен: True
   ```

### 4. Тестирование отмены

- Если при запросе пароля экспорта нажать **Отмена**, должно появиться предупреждение:
  "Экспорт отменён: необходим пароль для шифрования"
  
- Если при запросе пароля импорта нажать **Отмена**, должен появиться вопрос:
  "Пароль не введён. Попробовать импорт без расшифровки?"

## Возможные проблемы и решения

### Проблема: Диалог не появляется

**Причина 1**: Диалог скрыт за основным окном
- **Решение**: Проверьте панель задач, возможно окно свернуто

**Причина 2**: `simpledialog` не импортирован
- **Решение**: Проверьте, что в файлах есть:
  ```python
  from tkinter import simpledialog
  ```

**Причина 3**: Диалог вызывается в неправильном потоке
- **Решение**: Убедитесь, что `simpledialog.askstring` вызывается в главном потоке GUI (до `threading.Thread`)

### Проблема: Ошибка при экспорте/импорте

Проверьте логи в консоли и убедитесь, что:
1. Мастер-пароль установлен (`self.master_password is not None`)
2. Пароль экспорта/файла был получен (проверьте DEBUG сообщения)
3. Методы `export_vault` и `import_json`/`import_lastpass` получают правильные параметры
