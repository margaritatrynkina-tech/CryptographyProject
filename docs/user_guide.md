## Установка и запуск

### Установка из исходного кода
1. Установите Python 3.8 или выше
2. Склонируйте репозиторий или скачайте исходный код
3. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите приложение:
   ```bash
   python main.py
   ```

### Установка из исполняемого файла
1. Скачайте `CryptoSafe Manager.exe` из релизов
2. Запустите исполняемый файл
3. Приложение создаст необходимые файлы конфигурации в папке пользователя

## Первоначальная настройка

### Создание мастер-пароля
При первом запуске вам будет предложено:
1. **Создать мастер-пароль** - основной пароль для доступа ко всем данным
2. **Настройки безопасности** - выбор профиля безопасности
3. **Настройки автоочистки буфера** - таймер автоматической очистки буфера обмена

### Рекомендации по мастер-паролю
- Используйте не менее 12 символов
- Комбинируйте буквы, цифры и специальные символы
- Избегайте использования личной информации
- Рассмотрите использование passphrase (фразы из нескольких слов)

## Основные функции

### Главное окно
Главное окно содержит:
- **Список паролей** - все сохраненные учетные записи
- **Панель поиска** - быстрый поиск по названию, логину или URL
- **Кнопки действий** - добавление, редактирование, удаление
- **Статус блокировки** - индикатор состояния сейфа

### Добавление новой учетной записи
1. Нажмите кнопку "Добавить" или Ctrl+N
2. Заполните поля:
   - Название (обязательно)
   - Логин/Email
   - Пароль (можно сгенерировать)
   - URL сайта
   - Заметки (опционально)
3. Нажмите "Сохранить"

### Генератор паролей
Встроенный генератор позволяет создавать безопасные пароли:
- Длина от 8 до 32 символов
- Типы символов: буквы, цифры, специальные символы
- Исключение похожих символов (l, 1, O, 0)
- Генерация по шаблону

## Работа с паролями

### Просмотр паролей
- Щелкните по записи для просмотра деталей
- Пароли по умолчанию скрыты звездочками
- Нажмите кнопку "Показать" для временного отображения

### Копирование данных
Для каждой записи доступны:
- **Копировать логин** - Ctrl+C
- **Копировать пароль** - Ctrl+Shift+C
- **Копировать все** - Ctrl+Alt+C

### Автозаполнение
Приложение поддерживает:
- Быстрое копирование в буфер обмена
- Автоматическая очистка буфера через заданное время
- Уведомления о копировании

## Буфер обмена и безопасность

### Настройки безопасности буфера
В настройках можно настроить:
- **Таймер очистки** - от 5 секунд до 5 минут
- **Автоочистка при блокировке** - автоматическая очистка при блокировке сейфа
- **Мониторинг буфера** - защита от слежки других приложений

### Защита от слежки
Clipboard Monitor предотвращает:
- Чтение буфера другими приложениями
- Сохранение паролей в истории буфера
- Утечку данных через буфер обмена

## Аудит и журналы

### Просмотр журналов
Откройте "Аудит" в главном меню для просмотра:
- Все операции с паролями
- Попытки входа
- Экспорт/импорт данных
- Изменения настроек

### Фильтрация и поиск
В журнале доступно:
- Фильтрация по типу события
- Поиск по ключевым словам
- Сортировка по дате
- Экспорт в PDF/CSV/JSON

### Проверка целостности
Приложение автоматически:
- Проверяет целостность журналов каждые 24 часа
- Уведомляет о подозрительных изменениях
- Ведет криптографически подписанные логи

## Импорт/экспорт данных

### Поддерживаемые форматы
- **CryptoSafe Encrypted JSON** (рекомендуется)
- **Bitwarden JSON**
- **LastPass CSV**
- **Обычный CSV** (пароли маскируются)

### Импорт данных
1. Выберите "Импорт" в меню
2. Выберите файл и формат
3. Настройте обработку конфликтов:
   - Пропустить
   - Заменить
   - Переименовать
   - Объединить
4. Просмотрите предварительные изменения
5. Подтвердите импорт

### Экспорт данных
1. Выберите "Экспорт" в меню
2. Выберите формат
3. Укажите пароль для шифрования (для Encrypted JSON)
4. Выберите данные для экспорта
5. Сохраните файл

### Обмен паролями
- **Безопасный обмен** через зашифрованные файлы
- **QR коды** для обмена публичными ключами
- **Эфемерный режим** для временного обмена

## Профили безопасности

### Standard (Стандартный)
- Автоочистка буфера: 30 секунд
- Автоблокировка: 5 минут неактивности
- Базовый мониторинг активности

### Enhanced (Усиленный)
- Автоочистка буфера: 15 секунд
- Автоблокировка: 2 минуты неактивности
- Расширенный мониторинг
- Дополнительные проверки целостности

### Paranoid (Параноидальный)
- Автоочистка буфера: 5 секунд
- Автоблокировка: 30 секунд неактивности
- Полный мониторинг системы
- Panic Mode (режим паники) по горячей клавише

## Советы по безопасности

### Рекомендации по использованию
1. **Регулярно меняйте мастер-пароль** - каждые 3-6 месяцев
2. **Используйте разные пароли** для разных сервисов
3. **Включайте двухфакторную аутентификацию** где возможно
4. **Регулярно делайте резервные копии** данных
5. **Проверяйте журналы аудита** на подозрительную активность

### Что делать в случае компрометации
1. **Немедленно смените мастер-пароль**
2. **Проверьте журналы аудита** на несанкционированный доступ
3. **Смените все пароли**, сохраненные в приложении
4. **Создайте новый набор ключей** через настройки
5. **Экспортируйте данные** и создайте новую базу

### Резервное копирование
Рекомендуется:
- Хранить зашифрованные резервные копии в нескольких местах
- Использовать облачные хранилища с двухфакторной аутентификацией
- Регулярно проверять целостность резервных копий
- Хранить мастер-пароль отдельно от резервных копий

## Устранение неполадок

### Частые проблемы
- **Забыт мастер-пароль** - восстановление невозможно, требуется сброс базы
- **Повреждение базы данных** - используйте резервную копию
- **Проблемы с буфером обмена** - проверьте настройки разрешений
- **Ошибки импорта/экспорта** - убедитесь в правильности формата файла

### Получение помощи
- Проверьте документацию в папке `docs/`
- Создайте issue в репозитории проекта
- Обратитесь к сообществу пользователей
