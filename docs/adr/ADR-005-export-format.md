# ADR-005: Выбор формата экспорта

## Статус
Принято

## Контекст
Требуется экспорт для compliance, внешнего аудита и анализа в Excel.

## Решение
| Формат | Назначение |
|--------|------------|
| **Signed JSON** | Полные записи + подписи + public key — независимая верификация |
| **CSV** | Анализ в таблицах, без подписей (метаданные только) |
| **PDF** | Человекочитаемый отчёт для печати/архива |

## Обоснование
Простой CSV не сохраняет подписи и цепочку — подделка тривиальна. JSON с подписями позволяет верификатору `AuditLogSigner.verify()` подтвердить каждую запись без доступа к приложению.

## Последствия
- Экспорт требует подтверждения мастер-пароля в GUI.
- Операция экспорта сама логируется как `AUDIT_EXPORT`.
