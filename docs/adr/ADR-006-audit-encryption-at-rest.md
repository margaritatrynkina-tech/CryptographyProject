# ADR-006: Шифрование audit_log.entry_data в покое

## Статус
Принято

## Решение
Поле `entry_data` шифруется AES-256-GCM; ключ выводится HKDF с context `audit-encryption` (отдельно от `audit-signing`).

## Обоснование
Подпись Ed25519 защищает целостность JSON, но не конфиденциальность на диске. Шифрование at rest закрывает утечку при копировании файла БД.

## Примечание
Подпись и хеш цепочки вычисляются по **открытому** JSON до шифрования; в БД хранится `ENC:` + base64(nonce||ciphertext).
